# Formocracy 游戏设定资料

本目录整理自 `tmp/pdfs` 中的 PDF 导出页、文本提取稿与视觉参考图。重复渲染版本和 Godot `.import` 缓存未收入归档。

## 01 - 世界观

- `世界观摘要.md`：从现有设定稿提炼的核心世界观、制度逻辑与三日 Demo 展开方式。
- `个人证明资料世界观档案.pdf`：12 页完整世界观设定稿，介绍证明资料的制度意义和玩法用途，以及身份证、居住证明、医疗急件证明、慢性病登记卡、水电缴费单、工作单位证明、主管担保函、污染暴露检测单、证据封存申请和主管保障券。
- `个人证明资料世界观档案-文本稿.txt`：世界观档案全文的可搜索文本版本。

## 02 - 行政制度

- `第十二区行政指导手册.pdf`：20 页完整设定稿，涵盖手册定位、实体交互、规则权威层级、章节结构、行政职能、表单、证明材料、例外条款与剧情用法。
- `第十二区行政指导手册-文本稿.txt`：手册全文的可搜索文本版本。

## 03 - 视觉参考

- `个人证明资料-页面总览.jpg`：12 页档案总览。
- `个人证明资料-线框稿总览.png`：未嵌入正式游戏资产的页面线框版本。
- `现有表单模板总览.jpg`：当前表单模板参考。
- `菜单文档资产总览.jpg`：主菜单文档资产参考。
- `证明文件资产总览.jpg`：证明文件视觉资产参考。

## 整理说明

- 行政手册采用 `admin-handbook-pdf` 中分辨率较高的 20 页 PNG 版本。
- 证明资料档案采用 `worldbuilding_forms` 中内容完整且已嵌入游戏资产的 12 页版本。
- `worldbuilding.txt`、`worldbuilding_forms/content.txt` 和 `proof-documents-source/source.txt` 内容完全相同，因此只保留一份文本稿。
- `admin-handbook-html`、`worldbuilding-pages` 和 `proof-documents-source` 中的重复分页未再次收入。
- 原始资料仍保留在 `tmp/pdfs`，本目录是便于阅读和交付的整理版。
