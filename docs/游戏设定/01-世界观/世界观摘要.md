# Formocracy 世界观摘要

## 核心设定

故事发生在衡川市第十二区。这里的制度不会直接判断一个人的真实处境，而是先判断他是否拥有能被机器、窗口和档案承认的证明。一个人即使真实存在、正在受苦，如果身份、地址、资格或紧急程度无法被转写成合规资料，也可能从资源分配体系中消失。

玩家扮演行政窗口工作人员。每次检查附件、核对字段和盖章，都在决定某段现实能否进入制度，并最终转化为水、电力、医疗、保护或封存措施。

## 证明资料的五种制度作用

1. 身份验证：确认申请人是谁，防止代办、冒领、封存身份和旧身份混用。
2. 资格验证：判断申请人是否有权取得资源、通道或保护。
3. 地址验证：确定事项属于哪个片区、受灾区或资源管辖范围。
4. 紧急验证：把医疗、污染、供水和灾后伤害转化为行政优先级。
5. 风险提示：标记审计、腐败、封存、污染扩散或公共损害。

## 制度与现实的矛盾

- 身份证证明的不是人的存在，而是制度愿意承认此人存在。
- 居住证明可以让一个没有搬走的人，仅因地址编号变化而失去救助资格。
- 医院急件证明把痛苦翻译成“可以插队”的等级。
- 慢性病登记卡把持续生存需求转化为系统中的固定资源占用。
- 主管担保函和保障券让权力关系获得比普通事实更高的行政权重。
- 证据封存申请试图保护真相，但也可能成为把真相锁进档案的工具。

## 三日 Demo 的世界观展开

- Day 1：身份证、居住证明和水电缴费单，建立“姓名、地址、资格必须一致”的基础秩序。
- Day 2：医疗急件、慢性病登记、工作证明和主管担保进入案件池，资源稀缺开始与权力特批发生冲突。
- Day 3：污染暴露检测、证据封存和旧档案揭示第七码头事故，并把玩家的行政决定连接到更大的制度责任。
