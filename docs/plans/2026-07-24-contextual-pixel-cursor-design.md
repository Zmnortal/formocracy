# 情境化像素鼠标系统设计

## 目标

为游戏建立一套统一的情境化像素光标，让玩家无需阅读提示就能理解当前对象可以点击、抓取、拖动或放置。光标只在可交互对象上切换，普通区域保持默认像素箭头。

光标不仅承担可用性提示，也表达玩家的身份：所有手势都来自同一只穿深橄榄色制服袖口的手，使玩家始终以体制内工作人员的身体参与表单流程。

## 交互原则

光标状态按以下优先级判断：

1. 普通区域使用默认像素箭头。
2. 进入可交互对象后，切换为该对象请求的手势。
3. 按下鼠标开始拖动后，锁定为抓紧状态，避免经过其他节点时闪烁。
4. 拖动物进入有效接收区后，切换为可放置状态。
5. 只有明确拒绝当前物品的目标才显示禁止放置状态；普通空白区域仍显示抓紧状态。
6. 松开、取消或完成交互后，根据当前悬停对象重新计算状态。
7. 暂停、切换场景和打开开发者控制台时清空瞬时状态。

## 状态映射

| 状态 | 表现 | 使用场景 |
| --- | --- | --- |
| `DEFAULT` | 像素箭头 | 非交互区域、禁用控件 |
| `POINT` | 食指指向 | 按钮、勾选框、地图地点 |
| `POINT_PRESSED` | 食指压下一帧 | 按钮按下反馈 |
| `GRAB` | 张开的手掌 | 可拖动文件袋、表单、附件 |
| `GRABBING` | 握紧的手 | 正在拖动物件 |
| `DROP_VALID` | 向下放置的手与绿色基准线 | 文件袋、验收区或机器接收口接受当前物品 |
| `DROP_INVALID` | 握物手与暗红叉号 | 明确拒绝当前物品的目标 |
| `OPEN_ENVELOPE` | 两指捏住封口 | 文件袋可拆封区域 |
| `STAMP` | 手握印章向下 | 可抓取和操作印章 |

签字与勾选在第一版共用 `POINT`。待签字玩法成为独立步骤后，再增加握笔光标。

## 主玩法映射

- 文件袋：`GRAB` → `GRABBING`；封口热区使用 `OPEN_ENVELOPE`。
- 表单与附件：`GRAB` → `GRABBING` → `DROP_VALID`。
- 绿色与红色印章：悬停时使用 `STAMP`，抓起后保持握章语义。
- 勾选框：`POINT`。
- 机器接收口：拖入有效文件时使用 `DROP_VALID`。
- 商店、地图、菜单与开发者控制台按钮：`POINT`。
- 锁定对象和禁用按钮：`DEFAULT`。

## 视觉规格

- 基础画布为 32×32 像素；握章等复杂姿势允许使用 40×40。
- 最近邻采样，不使用平滑缩放。
- 手部使用偏灰黄色肤色、深橄榄绿色制服袖口、黑褐色轮廓和少量旧黄铜高光。
- 可放置状态使用两至三像素绿色基准线。
- 禁止状态使用小型暗红叉号。
- 正在拖动状态相对张手姿势向右下偏移一像素，强化按压感。
- 只为按钮按下和有效放置提供必要的两帧反馈，不持续播放动画。

每张光标单独导出透明 PNG。热点必须位于真实接触位置：食指在指尖、张手在掌心、印章在印章底面、放置手在手掌下沿。

## 技术架构

新增自动加载的 `CursorManager`，由它调用 `Input.set_custom_mouse_cursor()`。管理器维护：

- 当前语义状态；
- 当前拖动锁定状态；
- 各交互节点提交的光标请求及其来源；
- 拖动结束后需要恢复的悬停状态。

交互模块只报告语义，不直接加载或设置图片：

```gdscript
CursorManager.request_cursor(CursorManager.Cursor.GRAB, form)
CursorManager.begin_drag(form)
CursorManager.set_drop_valid(receiver)
CursorManager.end_drag()
CursorManager.release_cursor(form)
```

请求携带来源节点。节点离开、释放或销毁后，管理器移除对应请求，从而避免重叠控件造成状态覆盖或光标遗留。

## 异常处理

- 找不到某张自定义图片时，回退到系统箭头而不是中断场景。
- 当前请求来源被释放时，立即重新计算剩余请求。
- 切换场景、暂停或失去窗口焦点时结束拖动锁定。
- 有效接收区在拖动过程中失效时，从 `DROP_VALID` 恢复为 `GRABBING`。
- 禁用控件不得继续保留 `POINT` 请求。

## 验收与测试

自动测试覆盖：

- 请求和释放后状态正确；
- 拖动状态不会被普通 hover 覆盖；
- 有效与无效放置状态可以实时切换；
- 松开后恢复当前悬停对象的状态；
- 来源节点销毁后不会遗留状态；
- 场景切换和暂停后恢复默认状态。

视觉验收覆盖：

- 深色建筑背景、浅色表单和人物区域上均能看清轮廓；
- 热点与实际点击位置一致；
- 全屏、窗口缩放和不同拉伸比例下光标尺寸稳定；
- 拖动过程中不闪烁、不突然跳回系统光标；
- 所有不可操作对象不会错误暗示可点击。
