# 每日晨间上班序列设计

## 目标

把每个工作日的开始从“直接出现工作台”改为一段有生活惯性和制度压迫感的固定仪式：

`职员宿舍看报 → 侧视腿部走路播片 → 办事厅入口 → 嘈杂声先进入 → 环境声渐退 → 内部广播简报 → 工作台`

项目吉祥物与引导者正式称为“秘书”，对外使用复古企业卡通猫作为标准化界面化身，但没有公开姓名、真实外形或可核验的所属机构；猫形象不等于真实身体。在本段流程中，秘书仍以来源未登记的“内部广播”出现，使其可以同时被理解为人、AI 或制度本身。完整定义见 `docs/narrative/secretary.md`。

## 交互原则

- 报纸、走路四拍和推门动作全部复用 `DialogueBox`。
- 第一次点击只补全当前文字，第二次点击才进入下一拍。
- 不使用计时器自动切画面，也不自动播放下一句。
- 允许自动发生的只有画面淡入淡出、短促换拍黑场和音量渐变。
- 读档恢复到工作中时不重复播放晨间序列；只有真正开始新工作日才进入。

## 分段

### 1. 家中看报

背景使用职员宿舍 12-C。报纸以大幅近景压在桌面上，包含当天版号、社会新闻标题和制度变化的公共说法。七天内容由 `data/narrative/pre_work_sequence.json` 配置。

报纸不直接替代行政手册或内部简报：

- 报纸提供社会表象与模糊措辞。
- 内部广播提供当天必须执行的规则。
- 两者之间的差异构成玩家理解世界的空间。

### 2. 走路播片

复用已确认的四张中性腿部侧视画面，只出现下半身、地板、墙和门。四拍分别为迈步、继续、停顿、恢复。心理活动保持短句和重复结构，不补充主角性别。

### 3. 办事厅入口

最后一拍停在办事厅门外。大厅人声先以较高音量出现，玩家再次确认“推门进去”后才进入工作台。

### 4. 广播显现

工作台出现时不立即以干净广播开场。嘈杂环境声先保留，随后在约一秒内压低，内部广播提示音和共享对话框再出现。广播每句话仍由玩家手动确认，简报结束后环境声恢复到正常工作音量。

## 每日入口

- 首日：职位恢复表验收完成后创建初始存档，再进入晨间序列。
- 后续日：宿舍确认休息或夜间收束推进日期后进入晨间序列。
- 存档恢复：按已有阶段直达工作台、日报或夜间，不重复晨间过场。
