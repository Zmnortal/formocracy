# 实体参考手册交互设计

## 目标

把上层文件柜中的参考手册从“打开抽屉后立刻出现阅读弹层”改为一个真实桌面物件。玩家必须先打开抽屉、取出闭合手册并放到桌面，随后点击手册才进入阅读状态。手册合上后可以继续拖动，也可以拖回已经打开的上层抽屉。

## 状态与转换

手册拥有四个互斥状态：

1. `IN_DRAWER`：上层抽屉打开时显示在抽屉中；关闭抽屉时隐藏。
2. `HELD_OR_MOVING`：由统一的 `DeskItemController` 负责拖动、置顶和落桌。
3. `ON_DESK_CLOSED`：闭合手册停留在桌面；单击进入阅读。
4. `READING`：显示全屏双页阅读层；实体书暂时隐藏且不能拖动。

从抽屉单击手册会把它取到默认桌面位置；直接拖动也会立即把柜内状态切换为空抽屉。只有闭合手册的中心落入已打开的上层抽屉投放区时才可归还。归还后播放短促收纳动画，并恢复柜内手册状态。阅读状态下按 ESC 或点击“合上手册”只关闭阅读层，不触发暂停菜单。

## 阅读层

阅读层使用一张透明背景的像素风双页纸质手册资产，页面正文继续由 Godot 标签渲染，避免把内容写死在图片中。每个跨页由左页标题/正文与右页标题/正文组成，后续可以替换为配置表。

左右下角分别提供卷边翻页区：只有存在上一页或下一页时才可点击。翻页先压缩并淡出当前正文，再更新页码和内容并展开，形成纸页掀动感。卷边承担视觉引导，按钮热区比卷边本身略大，兼顾像素画面与易用性。

## 输入与层级

文件柜保持前景层；实体书拖动时使用桌面物件统一的最高抓取层；阅读层高于文件、印章、NPC 和暂停前的普通界面，并拦截所有桌面输入。下层私人证物继续使用原有文件柜阅读层，不受实体手册改造影响。

## 验收

- 打开上层抽屉不会直接出现内容。
- 手册可取出、落桌、拖动、点击展开、前后翻页、合上并归还。
- 五态柜体切换时书与空抽屉没有重复图层。
- 卷边、页码、禁用状态和 ESC 行为正确。
- 文件审批、印章和下层证物交互无回归。
