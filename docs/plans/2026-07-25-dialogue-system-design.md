# 对话系统统一设计

## 目标

同一套文字、打字音效和状态规则，按叙事语境提供两种表现：

- 表单、内部播报和过场对话：使用屏幕底部的前景对话框，由玩家完全手动推进。
- 主游戏窗口前的 NPC 发言：使用人物附近、屏幕上方区域的气泡，不阻挡桌面操作，并在约 5 秒后自动消失。

## 共用规则

- 文字以每秒约 28 个字符的速度逐字显示。
- 非空白字符出现时播放短促、轻微随机变调的机械打字声。
- 新内容会中止并取代同一组件尚未完成的旧内容，避免异步等待悬挂。
- UI 使用像素字体、最近邻过滤与现有暗色金边视觉语言。

## 底部前景对话框

- 根节点覆盖 1280×720 设计画布，显示期间拦截鼠标，保证表单对话一定处于当前交互最前方。
- 面板位于画面底部，`z_index` 高于文件、表单与工作台普通 UI。
- 打字过程中按空格或点击鼠标，只补全当前句。
- 当前句完整显示后出现向右箭头；再次按空格或点击，才发出推进信号。
- 不设置自动推进计时器。
- 适用位置：每日简报、召唤下一位、商店主理人对话、夜间结算与提交结果。

## NPC 气泡

- 气泡位于人物右上方，尾巴指向当前窗口人物。
- `mouse_filter` 为忽略，不阻挡文件袋、表单、印章等主玩法操作。
- 气泡层级高于普通游戏 HUD，但不占用底部前景对话框。
- 逐字显示完成后停留约 5 秒，再快速淡出。
- 适用位置：NPC 到达窗口、递交材料、审批结果反馈等主游戏环境发言。

## 验证

- 组件测试覆盖打字状态、补全/推进两步输入、箭头、前景层级、音频导入和 NPC 五秒自动消失。
- 场景测试覆盖每日简报、召唤铃、商店、夜间地图和个人表单提交。
- 视觉快照分别检查底部对话框覆盖关系与 NPC 气泡位置、尾巴和可读性。
