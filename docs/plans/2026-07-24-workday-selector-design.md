# 工作日选择场景设计

主菜单的“游戏开始”不再直接启动游戏或弹出存档选择窗口，而是切换到独立的全屏工作日选择场景。

场景采用黑色背景、灰绿色分隔线和 Ark Pixel 字体。时间线左侧固定显示“新游戏”节点；存在存档时，其右侧显示一个工作日节点，包含存档修改日期、时间及当前工作日。选择存档会加载进度并进入工作台。选择新游戏时，若已有存档，页面切换到覆盖确认状态；没有存档则直接进入职位恢复 Opening。

底部“返回”和 Esc 回到主菜单。右下角垃圾桶仅在存在存档时可用，用于删除当前存档。删除前在同一全屏场景中显示确认状态，确认后刷新时间线并只保留新游戏节点。

当前版本继续使用单存档结构。场景从 `WorkdayState` 读取只读摘要，不因展示卡片而加载或修改游戏状态。后续扩展多存档时，可将节点数据源替换为摘要数组而无需重做页面布局。
