# 表单商店与黑市场景设计

## 目标

后半天地图增加两个可访问空间：正规表单商店与黑市。两个空间不直接出售货物，只发行用于申请货物、权利或档案的空白表单。玩家购买表单后，必须前往同一个官方申请局，消耗行动点填写并提交；审批结果、货物或退件于次日早晨送达。

这套循环承担三项功能：

1. 扩展夜间行动的资源决策。
2. 通过主理人对话推进人物关系。
3. 通过表单、审批批注和次日送达物逐步揭示失忆主角的过去。

核心循环为：

`进入空间 → 与主理人交谈 → 取得空白表单 → 前往申请局 → 消耗行动点提交 → 次日接收结果 → 组合记忆线索`

## 空间与主理人

### 正规商店：第十二区合作供销社

商店实际是一个受政府许可的“表单发行窗口”。空间明亮、秩序化，玻璃柜台后排列着按编号分类的表单抽屉。所有表单都有公开用途、工本费、申请条件和预计送达日。

主理人“周姨”五十多岁，认识复职后的林默。她知道林默住在职员宿舍 12-C、收入有限、经常忘记生活细节，却不了解主角失忆前的完整身份。她会根据当天状态主动交谈，例如注意到罚款、退件、连续缺席或异常购买记录。

周姨承担“无意间泄露线索”的叙事功能。她记得生活细节，也保存着一本未进入电子系统的旧账簿。随着关系深入，她会发现另一个姓名曾使用林默当前的住址，或者把无人领取的旧表悄悄塞进玩家档案袋。

### 黑市：废弃照相馆后室

黑市藏在废弃照相馆的后室，使用红色安全灯和暗柜陈列表单。这里出售的不是违禁品，而是制度本应关闭却仍可能被受理的请求入口：停用版本、内部专用表、注销表和被人为改造字段的表。

主理人“老赫”认识失忆前的林默，并认为林默曾背叛过某个组织。他第一次见面会使用旧称呼试探主角；主角没有反应后，他会怀疑林默是管理局派来的诱饵。

老赫不会直接解释过去。玩家需要通过旧回执、暗语选择、工作中的处理决定和正确填写黑市表单逐步取得信任。他可能故意隐瞒关键字段，利用申请结果验证主角是否仍保留过去的习惯与知识。

周姨提供“现在生活留下的破绽”，老赫提供“过去身份留下的证据”。两人的说法允许互相矛盾，玩家必须通过表单结果自行判断。

## 交易与场景演出

两个空间采用统一的实体化交互：

1. 主理人根据关系和当日状态主动对话。
2. 主理人从抽屉或暗柜中取出当日可发行的表单。
3. 玩家点击或拖动表单，查看正反面、编号、条件和风险信息。
4. 玩家把决定购买的表单放到柜台托盘。
5. 主理人盖下“已发行”章或私人暗章。
6. 空白表单进入玩家的个人档案袋。
7. 玩家返回地图，并前往官方申请局提交。

正规商店公开显示表单说明与预计送达日。黑市只显示编号、旧章和老赫的含糊提示，玩家需要利用已有线索判断真实用途。

购买只取得空白表单，不代表申请成功。余额不足时无法发行；已购买但当晚未提交的表单保留在个人档案袋中，可在后续夜晚继续使用。

## 官方申请局

所有表单，无论来自商店还是黑市，都通过同一个官方申请局提交。这是夜间玩法的核心空间。

玩家在申请局执行以下操作：

1. 从个人档案袋选择空白表单。
2. 填写申请字段。
3. 选择需要附带的回执、证件或证明。
4. 作出或拒绝真实性声明。
5. 消耗行动点，将表单送入官方受理机器。

附件缺失或字段可疑时仍允许提交，但更容易收到退回、补正或审查结果。受理机器不直接标注“黑市表单”，只检查编号、版本、申请权限、附件和身份是否匹配。

黑市表单可能产生以下结果：

- 旧版本仍被某台受理机接受。
- 表单有效，但主角缺少申请权限。
- 已注销编号仍指向运行中的仓库。
- 表单是诱饵，提交后触发内部审查。

高风险申请不直接结束游戏，而是生成可持续发展的审查记录、政治信用变化或后续剧情。

## 次日配送与记忆调查

第二天早晨统一播放投递和拆包演出。玩家可能收到：

- 获批货物。
- 退回件。
- 补正通知。
- 延期回执。
- 约谈单。
- 来源不明的封存袋。

失败申请同样能够提供线索。例如退回章可能带有主角失忆前所属部门的编号，补正通知可能暴露一项本不应存在的权限记录。

每件叙事表单包含四层信息：

1. 发行时的公开描述。
2. 主理人的交易台词。
3. 次日结果和主角观察。
4. 与其他证据组合后解锁的真实解释。

线索不由任何主理人直接讲明，而是通过表单、审批批注、送达物和工作案件之间的对应关系被玩家主动拼合。

## 首批表单

### 正规商店

1. **《旧物认领申请》**
   - 公开用途：认领无人领取的个人物品。
   - 次日结果：一只登记在另一个姓名下、却带有主角指纹的旧工具箱。
   - 叙事作用：建立“另一个身份”疑点。

2. **《个人档案节录申请》**
   - 公开用途：取得个人档案中的公开部分。
   - 次日结果：大量内容被涂黑，但页码显示档案曾被拆分。
   - 叙事作用：证明记忆缺失可能是行政处理结果。

3. **《私人通信终端购置申请》**
   - 公开用途：申请家庭通信终端。
   - 次日结果：终端中残留一个无法删除的旧联系人编号。
   - 叙事作用：开启后续联系人支线。

### 黑市

1. **《注销人员遗留物领取单》**
   - 表面用途：领取已注销居民的遗留物。
   - 次日结果：旧工具箱缺失的钥匙。
   - 叙事作用：与《旧物认领申请》组合，确认旧身份关联。

2. **《内部档案校勘申请》**
   - 表面用途：纠正内部档案中的编号错误。
   - 次日结果：退回件上出现主角失忆前的部门编码。
   - 叙事作用：将主角与管理局内部部门建立联系。

3. **《已停用住宅进入许可》**
   - 表面用途：进入一处已封存住宅。
   - 次日结果：许可可能获批，也可能触发监控标记。
   - 叙事作用：解锁后续实体地点与高风险调查。

## 配置结构

每张表单由统一配置驱动：

- `form_id`：唯一编号。
- `issuer_id`：发行主理人。
- `source_type`：正规发行或黑市流通。
- `purchase_cost`：空白表单工本费。
- `submission_cost`：提交消耗的行动点。
- `required_fields`：必填字段。
- `required_evidence`：附件要求。
- `risk_tags`：旧版本、权限不足、已注销、受监控等。
- `fulfillment`：批准后的次日送达物。
- `memory_clue_id`：可能解锁的记忆线索。
- `dialogue_conditions`：主理人主动对话条件。

主理人关系状态至少包括：是否认识主角、信任等级、已完成对话、已见证证据和已发行特殊表单。对话与表单目录由这些状态、日期、工作决定、政治信用和已发现线索共同决定。

## 首阶段范围与验收

首阶段只实现两个空间、两位主理人、每处三张表单，以及一条跨空间组合线索，避免过早扩展目录。

验收需覆盖：

- 进入空间时的条件对话。
- 表单发行、扣费与库存。
- 申请局选择、填写、附件和行动点消耗。
- 未提交表单跨夜保留。
- 次日结果与配送演出。
- 正规和黑市风险分支。
- 两件证据组合形成记忆线索。
- 主理人关系与存档恢复。
