# 日报结算板块揭示重构

## 目标

- 参考 `common_bg_demo.png`，把日报改为一张固定尺寸的行政回执。
- 删除主页面上的逐案长列表，避免复杂工作日产生纵向溢出。
- 让系统按字段组逐块宣读结果，而不是逐字打字。

## 信息层级

1. 标题：工作日处理回执 / 第 N 天。
2. 身份栏：回执编号、经办员、工作日。
3. 审批统计：形式审查、送交验收、批准、驳回、程序错误。
4. 效力状态：现实生效、等待设施处理、异常档案。
5. 财务行：日薪、绩效、罚款、生活支出。
6. 最终结余：本日结余与政治评价。
7. 人员声明：确认记录并结束工作日。

逐案记录仍写入存档与外部回执，但不再占用日报主视图。

## 动效

- 标题和空白回执先出现。
- 其余 9 个板块依次显现，默认间隔约 0.92 秒。
- 每块从下方 7 像素短促落位，并播放一次机械短音。
- 最后一块出现后才允许勾选声明和结束工作日。
- 动画针对整个字段/整行，不做逐字符打字。

## 验收

- 1280×720 设计分辨率下所有内容位于文书安全区。
- 5 件复杂案件及长申请人/事项名称不会改变日报高度。
- 逐案记录不在主页面绘制，但仍可由测试和外部桥接读取。
- 日报确认后仍进入下班地图。
