# 自由桌面物件与伪物理设计

## 目标

主玩法中的桌面不再是固定 UI 布局，而是一张可以由玩家长期整理的实体工作台。印章、呼叫铃、归档托盘、号码机、文件袋、表单和证明材料都可以被抓取。玩家能够将物件暂时拎到全屏任意位置；松手后，物件在伪重力作用下掉回桌面并产生轻微回弹。

背景、墙面设施、围栏、NPC、菜单和开发者控制台不属于可移动桌面物件。

## 统一桌面物件系统

使用统一的桌面物件控制器管理拖拽，不为每一种物件分别实现一套移动逻辑。每个可移动物件注册以下信息：

- `item_id`：稳定且可用于存档的唯一标识。
- `position`：设计画布中的当前位置。
- `size`：用于落点和边界修正的实际交互尺寸。
- `movable`：是否允许抓取。
- `interaction_type`：普通物件、工具、文件或容器。
- `layer`：默认遮挡层级。
- `motion_state`：`RESTING`、`HELD` 或 `FALLING`。

最后抓取的桌面物件显示在其他桌面物件上方，正在拖动或坠落的物件临时处于最高桌面层。菜单、开发者控制台和系统覆盖层始终高于桌面物件。

## 抓取与点击判定

按下鼠标后不会立刻认定为拖拽。指针移动超过阈值后进入 `HELD`；未超过阈值并松手则执行原有点击行为：

- 点击呼叫铃传唤 NPC，拖动呼叫铃只改变位置。
- 点击文件袋执行拆封，拖动文件袋执行搬运或投放。
- 印章以拖放为主要操作。

抓取期间可以把物件移动到全屏任意位置，不受桌面边界约束。物件会根据拖拽速度产生轻微倾斜，停止移动时逐渐回正，以表现重量和惯性。

## 坠落与桌面回弹

松手后物件进入 `FALLING`：

1. 垂直速度受伪重力影响逐帧增加。
2. 水平方向保留少量松手惯性，并逐渐衰减。
3. 物件落点超出桌面左右边界时，平滑修正至最近合法落点。
4. 物件接触 `DeskBounds` 后播放短促回弹和落桌音效。
5. 回弹幅度参考下落高度，但设置固定上限。
6. 动画稳定后进入 `RESTING` 并保存位置。

物件之间不进行真实物理碰撞。视觉上可以遮挡和重叠，但所有物件最终都落在同一个桌面平面，避免堆叠卡死、连锁碰撞和物件被挤出屏幕。

## 功能投放

物件接触桌面后再判断功能目标：

- 印章落在表单范围内时执行盖章。
- 表单或证明材料落在文件袋范围内时执行装袋。
- 封好的文件袋落在归档托盘范围内时执行归档。

没有命中功能目标时，物件正常停留在桌面。归档托盘是容器物件：托盘移动时，内部文件袋堆叠、数量显示和投放判定区域共同移动。

## 永久布局

稳定落桌后，将物件位置和桌面遮挡顺序保存到玩家存档。坐标使用 `1280×720` 设计画布空间，不保存窗口缩放后的屏幕坐标，因此全屏和分辨率变化不会破坏布局。

下一工作日进入工作台时恢复玩家上次的摆放结果。新增物件没有历史记录时使用默认位置。若后续桌面边界变化导致旧位置非法，加载时将物件修正到最近的合法桌面落点。

## 验证

自动测试覆盖：

- 点击与拖动阈值不会互相误触。
- 抓取期间物件能够离开桌面区域。
- 松手后物件最终落入 `DeskBounds`。
- 超出左右边界的物件能够回到合法落点。
- 印章、装袋、归档和铃铛原有功能保持有效。
- 归档托盘移动时内部堆叠和投放区同步移动。
- 保存并重新加载后恢复位置和遮挡顺序。
- 不同窗口尺寸下使用同一设计画布坐标。

画面验证覆盖从高处释放、边缘释放、多个物件重叠、托盘移动和跨工作日恢复布局。
