# NPC 动画动检台设计

## 目标

建立一个无需前端构建工具的本地 HTML 页面，直接读取 Godot 项目的角色本体与动画配置。它用于快速检查动作语义、逐帧完整性、播放节奏、后排黑度，以及人物与前景遮挡物之间的层级关系。

页面不是新的动画数据源。角色列表来自 `data/ontology/people.json`，动作、FPS、播放模式和帧路径来自角色对应的 `animation_table.json`。这样策划修改动画配置后，刷新页面即可看到同一份数据的结果。

## 页面结构

- 左栏：角色选择、动作列表、动作契约状态。
- 中央舞台：单人或排队预览；可选前景栏杆与桌沿遮挡。
- 底部时间轴：显示当前动作的所有帧，支持点击跳帧。
- 右栏：播放、暂停、重播、上一帧、下一帧、1–4 FPS、缩放、黑度、排队后排黑度和背景切换。
- 状态区：当前角色、动作、播放模式、帧序号、实际文件名和资源加载错误。

## 行为

页面遵守 `LOOP`、`ONCE`、`HOLD` 三种播放模式。默认使用配置 FPS，手动调速只影响本次预览，不写回 JSON。逐帧操作会暂停播放。排队模式复用当前角色帧展示三层人物，前排保持正常亮度，后排按设置逐级加深黑度。

页面使用项目内像素字体，无第三方 CDN 和运行时依赖。通过项目根目录启动静态服务器，避免浏览器阻止本地 JSON 与图片读取。

## 验收

- 林默、周循可从现有动画表加载全部动作与帧。
- 动作切换、播放模式、逐帧、重播和 FPS 控制正确。
- 图片加载失败时明确标出帧和路径。
- 单人/排队、人物黑度、缩放、栏杆/桌沿遮挡可即时切换。
- 桌面宽度下完整显示，在窄窗口下可纵向使用。
