# 第一日开工叙事播片设计（已并入每日晨间序列）

职位恢复表被验收机吞入后，不再出现“欢迎回来”面板、办公室四拍引导或具象化智能助手。

首日与后续工作日统一使用以下流程：

`职员宿舍看报 → 中性腿部走路四拍 → 办事厅入口 → 嘈杂声渐退 → 来源未登记的内部广播 → 工作台`

所有报纸、走路和推门画面都复用 `DialogueBox`，坚持首击补全、次击推进，不设置自动播放计时器。职位恢复表通过时创建初始存档节点，然后进入 `pre_work_sequence.tscn`。

完整内容、七日报纸配置、声音层级和验证标准见 [每日晨间上班序列设计](2026-07-25-daily-prework-sequence-design.md)。
