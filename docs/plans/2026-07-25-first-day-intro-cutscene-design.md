# 第一日开工叙事播片设计

## 目标

把职位恢复申请被验收机吞入后的“欢迎回来 / 我通过”静态面板，替换为一段四拍的手动叙事播片。播片既完成第一天开工的情绪铺垫，也留下前任经办员的轻微悬念。四拍之后由国家级智能协办员完成岗位引导，最后才进入第一份表单。

## 四拍内容

1. **尚未开放**：清晨的第十二区综合办事厅空无一人，窗口卷帘仍然关闭。
   - 档案记录：`05:58。第十二区综合办事厅，尚未开放。`
2. **工位恢复**：窗口内的灯亮起，老式广播与铁丝玻璃成为画面中心。
   - 内部广播：`职位恢复核验完成。B-07 工位已重新启用。`
3. **无署名便笺**：玩家工位上有一只冷掉的搪瓷杯、一把旧钥匙和一张没有署名的交接便笺。
   - 经办员：`杯子是冷的。纸条没有署名：第一份材料，替我再看一遍日期。`
4. **第一位来访者**：窗口开启，毛玻璃后出现手持文件袋、无法辨认性别的来访者轮廓。
   - 内部广播：`第十二区综合窗口，今日开始受理。`

## 国家级智能协办员

### 身份

- 正式名称：`中央现实管理系统协办智能体 M-0`
- 对外称呼：`墨墨`
- 形象：一只圆润的复古动画小猫，穿深绿色行政制服，胸前佩戴抽象行政徽记；琥珀色眼睛像持续工作的监控指示灯。
- 定位：不是普通桌面宠物，而是全国行政系统的统一智能接口。它可以播报政策、解释操作、提示错误，也会记录和评价玩家的决定。
- 性格：措辞友好、耐心、清楚，笑容始终不变；在“我会一直陪着你”之类的话里保留轻微的监督意味。

### 首次登场

四拍播片结束后不直接进入工作台：

1. 画面完全变黑，统一对话框显示 `系统 / ……`。玩家手动确认后才建立智能协办连接。
2. 墨墨在黑场中央亮起，依次说明自己的身份。
3. 墨墨提醒玩家每日政策会变化，必须先读当日简报。
4. 墨墨说明表单、身份证明与必要居住证明的核对职责。
5. 墨墨说明盖章后的档案还需要日终送验。
6. 墨墨明确所有判断都会留下记录，并让玩家开始处理第一份表单。

黑场和每一句墨墨台词都复用同一个 `DialogueBox`，遵循首击补全、次击推进，绝不自动播放。

## 交互规范

- 复用全游戏统一的 `DialogueBox`。
- 每句处于打字状态时，第一次点击或空格只补全当前句。
- 当前句完整后，第二次点击或空格才切换下一张画面。
- 不设置自动推进计时器，不提供“跳过播片”或单独的“我通过”按钮。
- 第四拍确认后进入黑场与墨墨引导；墨墨最后一句确认后才创建初始存档节点并进入 `main.tscn`。
- 主角只使用玩家填写的姓名，不出现性别、身体或人脸。

## 视觉与声音

- 四张画面采用一致的暗绿、氧化铜、脏奶油与微弱琥珀灯光。
- 每次切图使用极短黑场硬切，形成档案幻灯片般的机械顿挫。
- 第一拍以环境底噪开始；第二拍播放电流/灯光提示；第四拍播放窗口开放或开工提示音。
- 画面本身不烘焙台词，所有文字只通过 `DialogueBox` 显示。

## 验证

- 自动化测试覆盖：姓名提交后进入第一拍、等待不会自动换图、首击只补全文字、次击换图、四拍后进入黑场而不是工作台、墨墨引导不会自动推进、最后一句后才进入工作台、初始存档仅创建一次。
- GUI 快照覆盖第三拍、第四拍、纯黑连接拍和墨墨登场拍，确认生成图、底部对话框和人物主体无重叠。
