# 左侧双层文件柜交互设计

## 目标

把旧 session 已完成的文件柜素材接入主玩法，并让它承担两个彼此独立的长期功能：

- 上层抽屉：局务参考手册。保存流程、操作方法与世界规则。
- 下层抽屉：私人证物。保存主角跨工作日收集的私人线索，不与右侧当日归档托盘混用。

## 运行时状态

文件柜使用五张同尺寸、同柜体顶边对齐的透明贴图：

1. 关闭
2. 上层半开
3. 上层全开并露出手册
4. 下层半开
5. 下层全开并露出证物

点击抽屉后先显示半开帧，再切换到全开帧并淡入阅读层。关闭阅读层时按相反方向收回抽屉。过渡期间禁用两个点击热区，避免并发状态冲突。

五张运行时贴图统一采用轻微俯视的近正视角：柜体顶边、左右边与抽屉中线保持一致，共享同一块窄金属顶面，不显示外侧侧板。俯视程度与右侧职员工具柜一致；抽屉打开时通过内侧导轨和向前伸出的抽屉面表现纵深。完全打开的下层抽屉允许向画布下方延伸，因此序列以柜体顶部而非整张图片底部作为稳定视觉锚点。

## 阅读层

阅读层位于工作台最前方并拦截鼠标输入，避免玩家在阅读时误拖文件或盖章。面板从右侧展开，左边持续露出贴住画布边缘的柜体和当前打开的抽屉，不能用阅读面板遮掉柜体演出。

柜体按原始尺寸的 1.8 倍显示（在上一版 1.5 倍基础上再放大 1.2 倍），层级位于前景桌面之上。缩放时按素材的非透明边界贴住左墙；柜体与右侧职员工具柜统一下移 100 px，让两侧陈设落在同一前景高度。上下抽屉热区作为柜体子节点同步缩放。

- 手册提供“办理流程 / 操作方法 / 局务常识”三个页签。
- 证物层展示私人档案袋、散落线索，以及三件早期证物的文字记录。
- 右上角按钮或 ESC 可收起文件柜。

## 扩展边界

当前模块只负责展示和抽屉状态。未来可将手册页与证物列表改为配置表数据；柜体、热区与阅读层无需重写。
