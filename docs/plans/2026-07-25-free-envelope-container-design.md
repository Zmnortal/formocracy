# 文件袋自由容器设计

文件袋只承担容纳、展示和搬运职责，不承担流程门禁。案件创建时，配置中的全部文件都位于袋内；玩家可以任意抽出、放回、再次抽出，也可以在袋内为空、只有部分文件或包含全部文件时直接归档。文件袋是否打开、文件是否齐全、是否盖章，都不能阻止抓取、移动、打开、关闭或进入归档区。

运行时以 `packed_document_ids` 记录“此刻真正位于袋内的文件 ID”，而不是“玩家已经完成重新装袋”的任务进度。抽出文件时立即移除 ID，放回时立即追加 ID，并同步袋内可见堆栈。`all_documents_packed()` 仅作为最终检查工具保留，不再参与任何输入、拖拽或归档许可判断。

归档落下的一刻是案件状态的提交边界。提交模块从呈现器创建不可变 `envelope_snapshot`，记录袋内文件、预期文件、缺失文件、额外文件、文件数量、文件袋是否打开以及捕获时间。评分模块只读取这份快照生成程序错误并写入案件记录；归档模块再把同一快照复制进持久档案。动画期间玩家后续看到的节点隐藏、释放或案件切换不会改变已记录结果。

日终验收机展示所有待验档案，不按是否盖章或内容是否完整做预筛选。机器容量仍然是唯一的送验限制；错误档案可以被送验，并通过此前保存的快照和程序错误产生后果。
