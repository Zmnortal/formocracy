# FORMOCRACY 开场与 Day 1 像素素材接入设计

## 目标

游戏启动后播放三幕像素风开场。前两幕自动推进，玩家也可通过点击、空格或回车提前推进；第三幕保持显示，由玩家点击“开始第一天”进入主工作台。右上角提供跳过入口，开发者控制台可直接切换至开场。

## 场景结构

`scenes/opening.tscn` 是新的启动场景，以 1280×720 为逻辑画布，三张 16:9 图片使用覆盖裁切适配窗口。幕间使用短黑场淡入淡出。第三幕显示工作日提示与开始按钮。

主场景保留现有表单拖动、复选框、批准/驳回印章和验收提交逻辑，只替换视觉层。办公室背景、通讯终端、法规册、证件、附件、便笺、候选架、印章和验收机均来自 Day 1 拆层资源包。

## 资源与验证

素材复制到项目内部的 `assets/opening` 与 `assets/day1_8bit`，运行时不依赖 Obsidian Vault。像素纹理由 Godot 使用 nearest 过滤。验证覆盖开场推进、跳过、第三幕停留、进入主场景、开发者控制台场景切换和原有交互回归。
