# 验收机器吞入文件袋交互设计

## 目标

玩家完成盖章并将全部材料重新装回文件袋后，把文件袋拖到中央现实验收机器。文件袋进入入口感应区时产生磁吸和伪 3D 前倾预览；玩家松手后，机器通过传送、压缩和前景遮罩把文件袋吞入。案件仅在吞入完成后结算。

## 交互阶段

1. 文件袋处于可拖动状态。
2. 进入机器入口感应区后，位置向入口中心轻微吸附。
3. 文件袋通过横向略放大、纵向压缩和角度变化呈现向前倾斜的伪 3D 效果。
4. 指示灯显示黄色，提示松手即可投递。
5. 拖出感应区时恢复原始形态，投递取消。
6. 在感应区松手后锁定输入，文件袋吸附到传送带中心。
7. 文件袋沿机器方向移动并进一步压扁。
8. 机器入口前景遮罩覆盖文件袋，使其像进入机器内部，而不是直接透明消失。
9. 最后一角完全进入后，指示灯变绿，记录案件结果并推进 NPC 队列。

## 错误处理

文件袋未盖章或遗漏材料时仍允许投递。机器短暂显示红色反馈后继续吞入，程序错误写入处理记录。吞入开始后不可撤回，也不能重复提交。

## 实现边界

首版使用 Godot 2D 节点、Tween、缩放、旋转、层级和 `clip_contents` 遮罩完成，不引入 3D 场景或着色器。感应区应大于机器视觉入口，以保证拖放可靠。

## 验证

- 进入和离开感应区时形态可恢复。
- 松手后输入锁定且只提交一次。
- 吞入过程中有前景遮挡，而非单纯淡出。
- 动画完成前不写入案件结果。
- 完整和不完整文件袋都能完成流程，并产生正确的程序错误记录。
