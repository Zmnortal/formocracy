# FORMOCRACY 2D 可玩原型设计

## 目标

在 Godot 4.7 中建立一个纯 2D、可直接运行的桌面审批原型。第一版只验证处理实体表单的交互手感，不加入分数、绩效、倒计时、输赢或道德判定。

## 核心循环

1. 桌面中央出现一张申请表。
2. 玩家可抓取并拖动纸张。
3. 玩家可勾选或取消表单内的审查项。
4. 玩家拖动“批准”或“驳回”印章并在纸张上盖章。
5. 玩家将已处理表单拖入现实验收槽。
6. 验收机反馈接收状态，随后生成下一张申请表。

## 技术结构

采用 Node2D 与 Control 的混合结构：桌面、纸张、印章和验收槽使用 2D 世界节点；文字、复选框和状态提示使用 UI 节点。画面由 Godot 内置节点、默认字体、色块、线条和程序化绘制组成，不依赖外部美术素材。

视觉表现采用“纯 2D 逻辑＋轻度伪 3D”：桌面使用透视四边形，背景终端和验收机具有细微视差；纸张抓取时抬升、旋转并改变阴影，提交时缩小压扁并被验收槽遮蔽。第一版不引入 3D 摄像机、模型或法线贴图。

建议场景结构：

```text
Main (Node2D)
├── WorldBackground (Node2D)
├── Desk (Node2D)
│   ├── ApplicantTerminal
│   ├── FormWorkspace
│   ├── EvidenceArea
│   └── ValidationSlot
├── Forms (Node2D)
├── Tools (Node2D)
│   ├── ApproveStamp
│   └── RejectStamp
└── HUD (CanvasLayer)
```

## 表单与状态

首批表单包含住房、饮水、医疗三类。每份表单保存自身位置、勾选状态、印章类型和是否提交。系统只校验提交动作是否完整，例如是否已经盖章；不判断批准或驳回是否正确。

## 交互反馈

- 拖动纸张时轻微抬升、旋转并增强阴影。
- 复选框点击后立即显示墨迹勾选。
- 盖章时播放短促的缩放、回弹和油墨扩散动画。
- 验收槽接收表单时闪烁指示灯并显示简短官僚式回执。
- 不完整表单退回桌面，不造成分数损失。

## 验证标准

- 项目启动后直接进入主场景。
- 表单可以稳定拖动且不会丢失输入。
- 所有审查框可以独立切换。
- 两枚印章均可拖动并在表单上留下对应印记。
- 已盖章表单可以提交，未盖章表单会被退回。
- 连续处理多张表单时状态不会串联。
- 窗口缩放后主要交互区域仍保持可用。
