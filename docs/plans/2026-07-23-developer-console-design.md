# FORMOCRACY 开发者控制台设计

## 目标

为 Demo 开发阶段增加一个全局开发者控制台。控制台强调快速切换和一键准备测试状态，同时保留命令输入能力。它作为 Autoload 覆盖层存在，可在所有场景中打开。

## 打开方式

- 按反引号键 `` ` `` 打开或关闭。
- 屏幕右上角常驻一个小型 `DEV` 按钮。
- 项目设置 `debug/developer_console_enabled` 控制整个功能是否启用。

## 快捷面板

控制台顶部提供当前状态，主体分为选择器和快捷操作：

- 场景选择器：主工作台、工作日处理回执、验收机预览。
- 场景切换按钮：立即打开所选场景。
- 工作日数值选择器：直接设置当前工作日。
- 测试数据预设：空日报、全部批准、全部驳回、批准与驳回混合。
- 快捷按钮：填充三件测试申请、清空记录、进入下一工作日、重载当前场景。
- 实时状态：当前场景、工作日编号、已处理数量、日报触发进度。

## 命令终端

下半部分保留输出历史和命令输入框。首批命令：

```text
scene main
scene report
scene reload
report fill
day next
state
help
clear
```

未知命令只输出错误，不改变状态。上下方向键浏览命令历史。

## 行为约束

- 控制台打开时拦截鼠标和键盘输入，避免误操作下层场景。
- 场景切换后控制台保持存在并刷新状态。
- 日报测试数据只写入开发态 WorkdayState。
- 验收机预览复用现有概念图，不计入案件记录。
- 关闭开发配置后，DEV 按钮、快捷键和控制台全部隐藏。

## 验证标准

- 主工作台与日报均可通过快捷键或 DEV 按钮打开控制台。
- 场景选择器和按钮可以切换主工作台、日报与验收预览。
- 四种数据预设的日报统计正确。
- 工作日选择器、清空、下一日和重载操作正确更新状态。
- 命令接口与快捷按钮行为一致。
- 控制台关闭后下层场景恢复输入。
- Godot 解析、场景切换和自动化控制台测试通过。
