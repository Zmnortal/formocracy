# 下班后三个独立场景概念设计

## 共同构图

三个场景均采用 1672×941、16:9 的固定正面略俯视镜头。画面下方约四分之一是玩家直接操作纸张、档案袋或领取物的实体台面；中部是当前场景的主要机器或窗口；后景陈设负责解释机构功能和世界观。上方两角保持安静，供返回、行动点、时间和地点名称等界面信息使用。

整体保持冷淡、陈旧和制度化，但不再依赖大面积近黑色制造气氛。空间必须看起来仍在运转：冷色环境光负责读清结构，局部暖白工作灯强调可操作位置。

## 主理人与对白层

每个独立场景都有一位固定主理人。背景图不包含人物，主理人使用独立透明角色层，常驻画面左侧或右侧约 20% 宽的人物带，不遮挡中央操作区。主理人说话时轻微向中央前移，玩家开始操作纸张或机器后退回侧边。

所有场景共用底部对白框、逐字显示和普通人声逻辑，但对白内容与触发条件属于各自场景。点击主理人可以主动闲聊；进入场景、选择物品、操作成功、操作失败、余额不足、状态异常和准备离开时，主理人也可以插入一句短对白。闲聊不得消耗行动点，不得阻塞主要操作，也不直接给出谜题答案。

主理人的显示层级固定为：

`背景 < 场景机器与柜台 < 主理人 < 可拖动物件 < 对白框`

### 主理人焦点模式

玩家点击主理人或进入需要主理人确认的办理步骤时，场景切换到焦点模式：

1. 背景覆盖约 45%～60% 的冷黑遮罩，但保留地点轮廓。
2. 主理人放大至普通站位的约 1.35～1.5 倍并移动到画面中央。
3. 场景专属操作按钮分布在人物左侧和右侧；人物不再只是装饰立绘。
4. 下方固定显示主理人姓名和一句对白。
5. 选择具体办理动作后，侧边按钮淡出，恢复桌面、表单或物件操作。
6. 操作成功或失败后再次短暂进入焦点模式，切换人物状态并给出反馈。

按钮分工保持稳定：

- 左侧：准备动作，例如打开档案袋、出示证件、查看投递。
- 右侧：结果动作，例如提交申请、领取物资、确认休息。
- 下侧：对白、闲聊、确认与返回。

焦点模式不是独立菜单，而是覆盖在当前空间上的短暂人物交互层。关闭后玩家仍停留在同一个场景与同一个交互进度。

## 主理人阵容

### 第十二区合作供销社：周姨

沿用现有角色。她认识复职后的玩家，记得其生活习惯，负责发行空白表单。说话务实，会提醒余额、未提交表单和错误消费。

示例闲聊：

- “傍晚这阵人少。不是大家不缺东西，是工本费又涨了。”
- “你上次那张表字写得比以前工整。人倒是越来越糊涂。”

### 中央表单部：袁科员

四十岁左右的男性夜班受理员，制服整齐、脸色疲惫，始终隔着磨砂玻璃或站在受理机一侧。他不帮助玩家作决定，只确认机器接受了什么。

示例闲聊：

- “机器没坏。它只是不认可你放进去的东西。”
- “下班时间是给楼里的。表单没有下班时间。”
- “你当然可以再交一次。退件次数不设上限。”

### 公共配给站：马姐

五十岁左右的女性配给员，围裙外仍别着官方工牌。她负责资格核验和实物交付，记得附近住户最近领取过什么，说话直接而琐碎。

示例闲聊：

- “今天的水没有昨天黄。你就当这是好消息。”
- “罐子拿稳，摔坏了算你的，洒出去也算你的。”
- “隔壁楼已经来第三趟了。人没多，表倒是一张不少。”

### 职员宿舍 12-C：秦叔

六十岁左右的男性宿舍管理员，穿旧工作服，携带钥匙圈和维修记录夹。他常站在门边或通过门口管理窗出现，负责投递、设施报修和确认玩家结束夜晚，不进入玩家的中央书桌区域。

示例闲聊：

- “水管今晚响得轻，说明别处先停了。”
- “电表没走不代表有电，也可能是表坏了。”
- “门口那封不是我拆的。它来的时候就没有封严。”

## 场景专属交互

共同的对白系统不等于共同的玩法面板。每个场景只暴露与其职责有关的操作：

| 场景 | 主操作 | 主理人参与 |
|---|---|---|
| 商店 | 浏览、购买和取得空白表单 | 介绍、收费、盖发行章 |
| 中央表单部 | 填写确认、附件组合、正式提交 | 宣读校验结果、退回异常件 |
| 公共配给站 | 资格核验、票证交换、领取实物 | 核验证件、收票、推出配给物 |
| 宿舍 12-C | 阅读通知、填写个人表单、查看状态、休息 | 送达信件、评论设施、确认结束夜晚 |

每位主理人至少具备以下对白状态：

1. 初次进入。
2. 当晚再次进入。
3. 主动闲聊。
4. 操作成功。
5. 操作失败。
6. 玩家状态异常。
7. 离开场景。

## 中央表单部

### 场景用途

官方表单的填写确认、附件组合和最终提交地点。正规商店、配给站或其他渠道取得的空白表单最终在这里进入制度系统。

### 画面区域

- 中央受理机：投入表单，显示基本校验状态，并从下方托盘吐出回执或退件。
- 左侧附件区：放置证明材料、身份卡和需要核验的附件。
- 右侧退件区：接收补正通知、无效版本和异常表单。
- 下方操作台：左边放个人档案袋，中间放当前表单，右边放附件。
- 磨砂玻璃后方：只显示远处职员剪影，强化“系统有人维护但没有人真正负责”的感觉。

### 主要交互

`打开档案袋 → 选择表单 → 填写或检查字段 → 添加附件 → 投入受理机 → 取得回执`

## 公共配给站

### 场景用途

验证领取资格、交换票证并领取饮水或食品。它既可以发行配给相关空白表单，也可以在申请获批后交付实物。

### 画面区域

- 左侧资格窗口：身份卡、工作证或领取许可的核验。
- 中央票证窗口：提交表单或票证，进行登记与盖章。
- 右侧领取窗口：水罐、食品包和其他配给物从滑动托盘交付。
- 地面排队栏：用磨损箭头表达从左到右的流程。
- 下方操作台：三个独立落点分别对应证件、表单和领取物。

### 主要交互

`放入证件 → 核验资格 → 交付表单或票证 → 等待窗口处理 → 收取配给物`

## 职员宿舍 12-C

### 场景用途

夜间个人管理中心。玩家在这里阅读通知、填写个人表单、查看生活状态、整理次日材料，并选择休息结束夜晚。

### 画面区域

- 中央书桌：当前表单、档案袋、附件、信封和书写工具的主要操作区。
- 墙面状态板：用图形指示健康、饮水、食物和供电，不使用额外黑色信息面板。
- 左侧床铺：休息并结束夜晚。
- 右侧水槽、水罐和电表：把缺水、停电等状态变成空间里的真实物件。
- 门旁投递口：接收次日送达物、退件和补正通知。
- 窗户：提供冷色夜光及第十二区的生活背景。

### 主要交互

`阅读通知 → 从档案袋取表 → 在桌面填写 → 装入信封或整理附件 → 查看生活状态 → 休息`

## 后续物料拆分

每个场景后续至少拆分为：

1. 无交互物的基础背景。
2. 前景操作台及遮挡层。
3. 可点击机器、窗口或家具。
4. 表单、证件、附件、领取物和回执。
5. 状态灯、窗口灯和提交动画帧。
6. 场景进入、处理成功、失败与关闭状态。
