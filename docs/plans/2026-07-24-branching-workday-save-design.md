# 分叉工作日存档设计

## 节点语义

存档以“已完成工作日”为不可变节点。根节点“一开始”表示职位恢复完成、第一天尚未开始；“第一天”表示第一天全部流程完成，载入后从第二天开始。玩家从历史节点继续并再次完成下一天时，始终创建新的子节点，不覆盖已有后续节点。

每个节点包含唯一 `node_id`、父节点 `parent_id`、已完成天数 `completed_day`、创建时间、分支顺序和完整 `WorkdayState` 快照。完整快照优先于差量和事件溯源，以换取简单、稳定的恢复与调试。

## 临时进度与检查点

时间线检查点和防崩溃临时进度分离。日内普通保存只更新当前临时进度；Opening 完成时创建“一开始”；夜间流程结束、进入下一工作日前创建“第 N 天”检查点。载入历史节点后，该节点成为当前父节点；完成下一天时在其下创建新分支。

## 树状选择页面

根节点固定显示“一开始”。子节点按天数向右、同父分支纵向展开，并用连接线表示关系。点击节点先显示二次确认，确认后载入节点并进入下一工作日。垃圾桶删除选中节点及其全部后代，根节点不可删除。

## 兼容与安全

首次读取新版存档时自动迁移旧版单存档：已进入第 N 工作日的旧档转换为“第 N-1 天完成”检查点及第 N 天临时进度。写入采用临时文件验证后替换，并保留旧版备份。损坏节点不阻断其他分支。

## 验证

测试覆盖根节点、每日检查点、从同一历史节点生成两个下一天分支、分支状态隔离、级联删除、历史节点恢复、旧档迁移、失败写入保护，以及单线和多分支树的实际渲染。
