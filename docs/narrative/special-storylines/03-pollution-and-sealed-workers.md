# 特殊故事线 03：提前发生的污染与被封存的人

## 一句话概念

孟秋兰申请污染救助时提交了一份“日期不可能”的检测单。玩家逐渐发现，问题可能不是检测太早，而是官方把事故日期写得太晚。

## 核心人物

### 孟秋兰

- 48 岁，公共食堂配餐员。
- 长期替已经被注销的儿子保留配给位置。
- 她不以揭露阴谋为第一目标，只想让制度承认儿子曾经存在。

### 顾原

- 62 岁，夜间装配线领班。
- 掌握过事故当夜的工人名单。
- 他既可能是证人，也可能参与了最初的名单修改。

### 罗雨棠

- 32 岁，夜班电车售票员。
- 用废票根记录未进入官方时刻表的夜间乘客。
- 她保存着孟秋兰儿子最后一次乘车的票根。

### 黎素与魏岚

- 黎素负责修复被拆分的档案，知道缺页往往并非意外。
- 魏岚代表程序监察。她可能严格阻止越权，也可能故意留下可申诉的缝隙。

## 推荐底层真相

第七码头地下转供管线先发生泄漏，污染进入宿舍和夜间装配区域。工厂为了完成当期生产，没有立即上报。

数日后事故扩大，官方才登记污染事件。早期检测、夜班医疗和临时转运记录因此全部显得“早于事故”，成为最容易被判定为伪造的一批材料。

部分夜班人员在事故后被转送、注销或拆分进不同档案。孟秋兰的儿子没有明确死亡记录，也没有有效生活记录，成为一个被程序持续推迟确认的人。

## 三次窗口案件

### Day 5：P-44《污染暴露应急供水与临时安置申请表》

**表面需求**

孟秋兰家中自来水有异味，她本人出现皮肤灼伤，申请紧急净水和临时安置。

**材料**

- 身份证明。
- 第十二区居住证明。
- 水电缴费单。
- 污染暴露检测单。
- 医院急件证明。

**关键矛盾**

污染检测日期比官方事故日期早四天。

**可能解释**

- 检测单伪造。
- 采样日期填写错误。
- 官方事故日期并非真实开始日期。

**玩家选择**

批准紧急供水不等于承认事故日期。玩家可以先处理生存需求，再决定是否标记检测单进入复核。

### Day 6：A-73《公共事故封存证据临时解封使用申请表》

**表面需求**

孟秋兰希望查看儿子失踪前的污染检测、夜班名单和交通记录。

**材料**

- 孟秋兰身份证明。
- 亲属关系记录。
- 原证据封存编号。
- 污染检测单。
- 主管担保函或合法解封理由。

**规则冲突**

- 旧版手册允许直系亲属在生存状态不明时申请有限查看。
- 新修订页只允许“已确认死亡人员”的直系亲属申请。
- 孟秋兰的儿子恰好既未确认存活，也未确认死亡。

**玩家选择**

- 按新规则驳回。
- 依据旧页受理。
- 只允许查看，不允许复制。
- 延迟并要求档案索引室人工复核。

### Day 7：S-18《公共事故档案续封申请表》

**表面需求**

装配厂要求继续封存事故名单，理由是防止恐慌、保护调查和避免境外技术合作中止。

**材料状态**

所有签章可以合法，申请单位也确实具有申请资格。

**核心冲突**

申请单位同时是潜在事故责任方。续封会阻止孟秋兰完成 A-73，也会让早期污染日期无法进入公共记录。

**此案作用**

这不是“找出一个材料错误就能救人”的案件，而是要求玩家明确选择由谁承担不确定性。

## 证据链

| 证据 | 持有人或来源 | 证明范围 | 风险 |
|---|---|---|---|
| 早期污染检测单 | 孟秋兰 | 污染可能早于公告 | 容易被判伪造 |
| 夜班工人名单 | 顾原 | 某些人曾在事故区域工作 | 顾原可能修改过名单 |
| 最后乘车票根 | 罗雨棠 | 孟秋兰儿子事故前曾乘坐夜间线路 | 票根不是正式身份记录 |
| 非正式线路作业证明 | 林默故事线 | 夜间线路确实运行 | 与住房申请目的无关 |
| 验收机同步记录 | 宋铎故事线 | 截止时间曾被人工调整 | 不能单独证明事故责任 |
| 缺页索引 | 黎素 | 档案原本存在更多页面 | 查看本身可能构成越权 |

## 建议变量

- `meng_emergency_relief`：是否获得净水与安置。
- `early_pollution_evidence`：未发现 / 标记 / 复核 / 正式入档。
- `archive_access_level`：无 / 延迟 / 查看 / 复制。
- `missing_worker_list`：未知 / 知道存在 / 获得残页 / 获得完整名单。
- `factory_seal_status`：续封 / 有限解封 / 拒绝续封。
- `meng_trust`：孟秋兰是否相信玩家会让记录产生现实结果。

## 分支结局

### 继续封存

玩家维持现行程序，工厂和监察压力下降。孟秋兰不会得到儿子的正式状态，但可能把私人材料交给夜间网络。

### 有限解封

孟秋兰只能查看部分档案。她确认儿子曾在名单中，却不能取得可用于申诉的正式副本。这是最符合官僚逻辑、也最残酷的中间结果。

### 拒绝续封

档案进入公开复核，玩家面临严重监察。若缺少林默、宋铎或罗雨棠的旁证，早期检测仍可能被定为伪造。

### 解封但拒绝污染救助

玩家帮助恢复历史，却没有解决孟秋兰当天的生存问题。结局应明确指出这种“追求真相、忽略当下”的代价。

## 不应写成什么

- 不要让孟秋兰只想曝光工厂，她首先是一个想确认儿子存在过的母亲。
- 不要把顾原简单写成坏人；他可能因为保住其他工人的配给而修改过名单。
- 不要让一张票根成为万能证据。
- 不要把拒绝续封直接写成完美结局，公开档案也可能导致工人失业、境外合作中止或证人被调查。
