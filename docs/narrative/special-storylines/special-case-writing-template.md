# 特殊剧情表单写作模板

## 用途

每新增一宗特殊剧情表单，都应同时完成行政玩法、人物叙事和后续回访设计。不能先写一段剧情，再随意找一张表单承载。

## 一、真实生活需求

用一句具体的话说明申请人今天为什么必须来到窗口。

不要写：

> 申请人提交一份主申请表。

应该写：

> 申请人需要在宵禁后前往第五诊疗站复查尚未愈合的工伤。

## 三、表面错误

玩家第一次阅读就能检查的内容：

- 漏填、日期、签名或表号。
- 姓名、公民序号、地址或有效期。
- 签发机关权限。
- 附件与表单字段不一致。

## 四、剧情矛盾

材料即使真实，也无法被当前规则完整解释的部分：

- 哪两个事实互相冲突？
- 是材料错误、规则遗漏，还是官方记录本身有问题？
- 玩家当前最多能确定什么，仍然不能确定什么？

## 九、回访载体

不必每次都让同一人物重新排队。可选择：

- 次日再次递交表单。
- 文件袋中的补件。
- 夜间地图对话。
- 秘书电话。
- 手册批注或修订页。
- 退回件、空座、医院记录或配给记录。
- 另一个人物携带的关联材料。

## 十、验收检查

- 表单拥有完整、具体、可信的名称。
- 申请人有明确的现实需求。
- 玩家能依据手册检查材料，而不是猜编剧意图。
- 剧情线索不等同于直接答案。
- 批准、驳回和延迟都有现实后果。
- 即使玩家此前做出不同选择，案件仍能以替代证据或补件方式继续。
- 不存在无代价的完美选择。
- 玩家主角不被写成林默；林默始终是 NPC。
