# 特殊故事线 02：被改动的时间与生存资源

## 一句话概念

许桥的医疗证明因为“迟到”失效，杜春梅的生存资源因为“排序”被挤占；两宗看似无关的案件最终指向同一个事实：机器记录的时间和优先级都曾被人调整。

## 核心人物

### 许桥

- 25 岁，区域文件递送员。
- 急于证明自己仍能工作，掩盖尚未痊愈的工伤。
- 曾经递送过一只与第七码头事故有关的封存袋。

### 杜春梅与周循

- 杜春梅 69 岁，退休电话接线员；周循 44 岁，是她的儿子和主要照护者。
- 杜春梅记得一些已从系统中消失的人名，但记忆不稳定。
- 周循更关心她能否获得净水与药品，不相信追查旧事能改善生活。

### 宋铎

- 52 岁，日终验收机房维护人员。
- 北陆联邦籍境外专家，持专家许可和第十二区境外人员居住证明。
- 知道机器时间和截止线可以被人工调整。
- F-09 是他本人延续居住许可的申请；他能维护衡川的机器，却没有本市身份证明。

## 推荐底层真相

事故当夜，大量医疗、污染和劳动材料在截止时间附近送达。上级要求验收机提前进入日终状态，以阻止未经确认的事故材料自动进入正式档案。

机器时钟因此被向前调整二十三分钟。许桥的医疗急件和一批事故文件被系统判定为迟到。宋铎执行了调整，但他只收到“设备同步”的技术命令，没有看到完整行政目的。

这个真相不证明宋铎无罪，也不把他写成幕后主使。他是制度中的执行者，同时也是少数能够证明机器并非中立的人。

## 四次窗口案件

### Day 2：M-31《非计划医疗通行申请表》

**表面需求**

许桥需要在宵禁后前往第五诊疗站复查工伤。

**材料**

- 许桥身份证明。
- 第五诊疗站医院急件证明。
- M-31 通行申请。

**关键矛盾**

医院登记时间在截止前，验收机回执却显示晚了二十三分钟。

**玩家选择**

- 按验收时间驳回。
- 依据医院原始时间批准。
- 延迟并要求人工复核。

**回响**

驳回会使许桥继续工作并加重伤势；批准会留下越过机器回执的程序记录；延迟可能让他错过当晚复查。

### Day 3：R-09《家庭配给领取人变更申请表》

**表面需求**

杜春梅希望让周循代领家庭配给。

**关键异常**

杜春梅在旧领取人一栏写下一个系统中不存在的人名，并说自己曾在事故当晚接通过那个人的电话。

**此案作用**

不直接证明机器时间问题，而是第一次说明“系统不存在”与“现实中不存在”不是同一回事。

### Day 4：F-09《境外专业人员居住许可延续申请表》

**表面需求**

宋铎申请延长验收机维护期间的境外专家居住许可。

**材料与当日变化**

- 宋铎提交北陆旅行证、认证译文、境外专家居住证明和本区单位工作证明。
- 当日互惠条款暂停，只有紧急维修令能够形成例外。
- 玩家核验维修令时，会看到事故当夜的“人工时间同步”记录。

**关键选择**

玩家是否把技术维护记录视为与居住申请无关的附件，还是保留副本。

### Day 5：M-52《慢性病生存资源优先验收申请表》

**表面需求**

杜春梅申请高优先级净水与医疗验收位。

**材料**

- 身份与居住证明。
- 慢性病登记卡。
- 医院急件证明。
- 当日资源优先申请。

**关键冲突**

材料全部有效，但当天只剩一个高优先级位置。系统同时标记该位置可能被主管保障券预留。

**此案作用**

把“机器时间是否正确”的技术问题推进为“系统排序是否正当”的政治问题。

**已接入的死亡条件**

- 第六夜结算时，系统检查 M-52 的最终归档。
- 只有“批准”且状态已经由验收机改为 `EFFECTIVE`，杜春梅才会活过本轮资源周期。
- 驳回、遗漏，或虽批准但仍停留在 `ARCHIVED`，都会触发第七日清晨的上班路事件：杜春梅倒在现实校验局外，救护车将她带走后确认死亡。
- 第七日晨间先播放九镜头的手动逐帧过场：路口、人群、闭眼、救护车、担架、车辆离开与遗留物空镜；玩家点击才推进，画面带轻微运镜，结束后进入正常工作。

## 关键线索

| 线索 | 来源 | 作用 |
|---|---|---|
| 二十三分钟时间差 | 许桥的医院证明与验收回执 | 建立可重复核验的异常 |
| 日终同步维护记录 | F-09 紧急维修附件 | 证明时钟可由人工调整 |
| 方澄的手写批注 | 第五诊疗站 | 证明医院端时间没有修改 |
| 宋铎的签名位置 | 维护记录 | 证明他执行过调整，但不能证明命令来源 |
| 杜春梅记得的不存在姓名 | R-09 | 把时间异常连接到被注销人员 |
| 主管保障预留标记 | M-52 | 预告第七天 V-01 |

## 建议变量

- `xu_medical_result`：驳回 / 延迟 / 批准。
- `xu_health_state`：稳定 / 恶化 / 无法工作。
- `clock_anomaly_level`：未知 / 怀疑 / 技术确认 / 获得证词。
- `song_cooperation`：拒绝 / 模糊说明 / 提供维护记录 / 正式作证。
- `du_priority_status`：普通 / 医疗急件 / 高优先级。
- `du_resource_reserved`：是否为杜春梅暂留资源。
- `du_death_registered`：第六夜结算后，是否已经锁定第七日上班路死亡事件。

## 分支回响

### 相信机器

玩家程序记录最整洁，但许桥的伤势恶化，宋铎不会主动提供更多资料。第七天面对保障券时，玩家缺少证明系统曾被人为调整的证据。

### 相信人工材料

许桥得到医疗通行，方澄信任提升。监察处会记录玩家多次以人工文件覆盖机器结果。

### 坚持复核

证据最完整，但人物承受等待成本。许桥可能因继续投递而再次受伤，周循可能转向非正式渠道寻找净水。

### 提前为杜春梅保留资源

第七天主管保障券出现时，冲突会更直接：玩家必须撤销自己先前的保留决定，或者公开拒绝特权兑付。

### 只盖批准章、没有完成验收

玩家在程序上作出了善意决定，但档案没有及时进入现实效力。杜春梅仍然死亡。这个分支用于明确游戏的核心命题：表面决定与真正生效之间存在会伤人的时间差。

## 不应写成什么

- 不要让验收机变成拥有恶意的人工智能。
- 不要把全部责任推给宋铎一个技术人员。
- 不要把杜春梅的记忆自动视为可靠证据；它应当提供方向，而不是直接完成证明。
- 不要只用“数值不够”解释资源冲突，必须展示具体哪个人会失去什么。
